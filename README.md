# 波動研究室｜七年級獨立研究

以操作、記錄數據、作圖與驗證模型為主的互動實驗台。研究紀錄與散點圖由學生在紙本學習單完成。

## 實驗

- **繩波**：頻率、振幅、繩子設定、觀察位置可調；可開啟尺規、計時器、參考線、追蹤點及時間圖。
- **船向岸邊開**：調整初始離岸距離與船速，聲波在岸邊反射後由持續前進的船接收；接收時自動暫停並顯示時間。

支援播放、暫停、逐格、時間歸零與全螢幕。圖形依螢幕像素密度繪製，維持固定比例。開啟尺規後，可在圖上點兩次量水平間隔。

## 使用

直接開啟 `index.html` 可離線使用，不需安裝套件、帳號或 API 金鑰，也不會收集學生資料。

GitHub Pages：在 Settings → Pages 選擇 Deploy from a branch，分支 main，目錄 / (root)。

## 模型條件

繩波採理想、均勻、無耗散模型。設定甲、乙、丙的波速分別為 2、3、4 m/s；位移單位 cm，位置單位 m，兩軸顯示比例不同。固定設定下的波速不隨頻率或振幅改變。

船實驗中空氣聲速固定 340 m/s，岸邊不動，無風；船等速朝岸邊前進。初始距離 100–3000 m、船速 0–50 m/s；動畫在接收時刻精確停止，時間顯示至小數點後三位。播放倍率只改變觀看速度。參數改變會將時間歸零。

所有數據是程式模型的結果，不是自然定律的獨立實驗證明。
